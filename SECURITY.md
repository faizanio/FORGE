# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within **Forge**, please do **NOT** open a public issue.

Instead, please send an advisory or email directly to the maintainers with:
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and suggested mitigations if known.

We will review the report promptly and coordinate a fix and release.

---

## Security Boundaries & Hook Safety

- Forge hooks are designed as **workflow enforcement and reliability controls**, not as an operating system kernel sandbox.
- When running commands generated by AI agents on your machine, always keep Antigravity's built-in sandbox, user permission confirmations, and terminal protections active.
